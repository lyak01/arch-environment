# Decisiones de diseño

- 16 categorías de suites.
- Brave como navegador predeterminado sugerido.
- XFCE como entorno sugerido para el perfil del autor.
- PulseAudio priorizado sobre PipeWire en hardware antiguo.
- Kernel LTS como preferencia base.
- Selección granular por suite: instalar todo, elegir manual u omitir.
- Detección automática de hardware, escritorio, audio y gestor de paquetes.
- Repos oficiales primero; repositorios personales como respaldo para paquetes huérfanos.
- Logs detallados y continuación ante fallos puntuales.
- Nunca copiar kernel, usuarios, red, drivers propietarios ni secretos sin confirmación.
